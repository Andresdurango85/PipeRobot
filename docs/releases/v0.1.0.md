# PipeRobot v0.1.0

The first release of PipeRobot, a CI quality gate for robot policies: on every pull request that
changes a policy, CI runs it in simulation many times, compares its success rate against a
stored baseline with a confidence interval, and blocks the pull request if it regressed.

This is a snapshot of Phase 0, the learning phase. It is meant for people who want to read,
run or reuse the gate; it is not on PyPI.

## What is in it

- **The gate core** (the `piperobot` package):
  - the results-file contract every evaluator writes;
  - the unpaired gate (Wilson and Newcombe intervals; PASS, WARN or BLOCK);
  - the paired same-seed comparison (exact McNemar test);
  - the pull request comment;
  - the evaluation history page;
  - verification of the history's signed certificates (`python -m piperobot.reports.certificate verify`).
- **Evaluators**:
  - PushT with LeRobot's VQ-BeT policy, on CPU;
  - the SO-101 arm placing tubes in a rack in Isaac Lab 3.0, on a Windows GPU machine, with a
    scripted privileged-state policy;
  - hand-scored trials on the real arm;
  - a mock for local demos.
- **GitHub Actions workflows**:
  - the PushT gate on every pull request (50 seeded episodes);
  - the SO-101 gate on 100 fixed seeds, paired against a reference, with videos of lost episodes;
  - a nightly paired run on 500 fresh seeds;
  - a signed success-rate history;
  - a CI job that runs the README's 30-minute reproduction on Linux and Windows;
  - security checks: CodeQL, zizmor, dependency review, OpenSSF Scorecard, and fuzzing of the
    input parsers.

## Upgrading

Nothing to upgrade from. Python 3.12 only. Install from a checkout (or the source tarball
below) with [uv](https://docs.astral.sh/uv/): `uv sync`; the
[README](https://github.com/Andresdurango85/PipeRobot/blob/v0.1.0/README.md) walks through a
first gate run in about 30 minutes.

## Known limitations

- The SO-101 gate evaluates a scripted policy that reads the simulator's state. It measures the
  pipeline and catches regressions, but it is not a deployable policy
  ([ADR 0034](https://github.com/Andresdurango85/PipeRobot/blob/v0.1.0/docs/decisions/0034-so101-scripted-privileged-state-policy.md)).
- The real-arm test (20 attempts) has not been run yet.
- The SO-101 gate needs a self-hosted Windows runner with an NVIDIA RTX GPU.

## Security

No vulnerability is publicly known in PipeRobot's own code. Five advisories in dependencies of
the optional `lerobot` extra are accepted as unreachable, with a review date
([ADR 0012](https://github.com/Andresdurango85/PipeRobot/blob/v0.1.0/docs/decisions/0012-dependency-vulnerability-triage.md)).
Report vulnerabilities privately as described in
[SECURITY.md](https://github.com/Andresdurango85/PipeRobot/blob/v0.1.0/SECURITY.md).
